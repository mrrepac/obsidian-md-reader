- Keep text in place when a center tap shows or hides app controls during
  immersive reading on phones. The header and mobile navigation overlay the
  page instead of shifting or shrinking the reading area.
- Reserve the system status-bar safe area in recent Obsidian phone layouts,
  keeping text and header controls below the clock and screen cutout.

  ends.

integration suites. Layout coverage includes repeated control toggles, different
safe-area sizes and restoration of host layout. Browser tests use a simulated
Obsidian host; physical iPhone verification is still pending.
