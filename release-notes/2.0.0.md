# MD Reader 2.0.0

This release adds quote collection, simpler appearance controls and more reliable
reading-position restoration.

## New

- Select text and save it with the **❞** button, context menu or **Save selected
  text as a quote** command. Quotes go to **Books/Quotes** by default, in one
  Markdown note per book, with a link to the book and chapter. The folder is
  configurable; existing unrelated notes are preserved.
- Visible **Menu** and **Aa** buttons next to reading progress, with keyboard access.
- Appearance presets: **Book**, **Compact** and **Night**, adjustable side margins,
  and an appearance reset. The book stays visible while changing settings.
- Text anchors for new reading positions and bookmarks. Reopening and reflow try
  to return to the same passage; the saved percentage remains the fallback.
  Existing saved positions and bookmarks remain supported.
- Independent switches for the progress bar, page number/percentage, chapter name
  and time left, available in Appearance and plugin settings ([#2](https://github.com/mrrepac/obsidian-md-reader/issues/2)).

## Fixes

- Opening a book from the library no longer saves 100% while its contents are still
  loading ([#1](https://github.com/mrrepac/obsidian-md-reader/issues/1)). Closing
  during a pending read also preserves the stored position.
- Correct bottom clearance when a theme changes the inherited font or footer height.
- Keep page content inside very narrow panes.
- Preserve the color swatches against theme button backgrounds, including hover.

Validation includes Node logic/UI tests and Chromium tests for layout, library
reopening, text anchors, appearance, progress controls and quote selection/storage.
The browser tests use a stubbed Obsidian host; they are not physical-device tests.
