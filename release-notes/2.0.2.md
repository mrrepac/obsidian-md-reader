# MD Reader 2.0.2

Fix a reading-position restoration bug that could reopen a book one page before
the saved position. When repeated phrases overlap the saved text fragment, the
reader now considers every matching occurrence instead of skipping the saved one
and selecting an earlier passage.

Validation: 89 logic checks, 98 UI checks and 33 Chromium reading integration
checks passed. Regression coverage includes overlapping text matches and closing
and reopening the reader at four screen widths. Browser tests use a simulated
Obsidian host; physical-device verification is still pending.
