# MD Reader 2.0.1

Fix the large empty space above the text on phones when immersive reading hides
Obsidian's floating or automatically hidden header. The reader now releases the
space reserved for that header while preserving the system status-bar safe area.
Showing the app controls or leaving immersive reading restores normal spacing.

Validation: 61 Chromium layout checks passed, including mobile header spacing
with different safe-area sizes. These checks use a simulated Obsidian host;
physical iPhone verification is still pending.
